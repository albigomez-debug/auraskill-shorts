Política de privacidad de AuraSkill Shorts

Última actualización: 9 de noviembre de 2026.

Qué hace la aplicación

AuraSkill Shorts es una herramienta de uso personal que sube vídeos al canal de YouTube de su propietario usando los Servicios de API de YouTube.

Datos que usa

La aplicación solo solicita el permiso youtube.upload para subir vídeos al canal del propietario. No lee, recopila, vende ni comparte datos personales de ningún usuario. El token de acceso se guarda cifrado como secreto en GitHub y solo se usa para subir vídeos.

Servicios de terceros

Esta aplicación usa los Servicios de API de YouTube. Al usarla aceptas los Términos de servicio de YouTube y se aplica la Política de privacidad de Google.

Cómo retirar el acceso

Puedes revocar el acceso en cualquier momento desde la página de permisos de tu cuenta de Google.

Contacto

Para cualquier duda sobre esta política, contacta con el propietario a través de su canal de YouTube.
